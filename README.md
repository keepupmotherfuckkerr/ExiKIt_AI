## Проблема

Когда сотрудник уходит из компании, вместе с ним уходят знания: незавершённые задачи, устные договорённости с клиентами, доступы, причины принятых решений. Передача дел обычно ручная, долгая и зависит от того, насколько подробно человек всё записал.

## Решение

ExitKit AI принимает заметки и документы сотрудника, извлекает из них структуру и собирает **Handover Package**: что за проекты ведутся, какие задачи открыты, кто за что отвечает, какие есть риски и что осталось неясным. Если данных не хватает, например нет ответственного или срока, приложение задаёт уточняющие вопросы, и отчёт обновляется.

```
заметки / файлы  ──►  локальная LLM (Ollama)  ──►  структура  ──►  уточняющие вопросы  ──►  PDF / Markdown
```

## Возможности

- 📄 **Любые материалы:** TXT, Markdown, PDF, DOCX или просто вставленный текст, несколько файлов за раз
- 🧠 **Структура из хаоса:** проекты, задачи, сроки, ответственные, риски, контакты, инструкции, договорённости
- 💬 **Уточняющие вопросы** по недостающим данным с автоматическим обновлением отчёта
- 🧾 **Экспорт** в PDF (с кириллицей) и Markdown
- 🔒 **Приватность:** анализ идёт локально через Ollama, данные не уходят во внешние сервисы
- 🧩 **Длинные документы** обрабатываются по частям, ничего не теряется молча
- 🌐 **Open source:** весь AI-пайплайн открыт, его можно изучать и менять

## Быстрый старт

Нужны [Python 3.11+](https://www.python.org/downloads/) и [Ollama](https://ollama.com/download).

```bash
git clone https://github.com/keepupmotherfuckkerr/ExiKIt_AI.git
cd ExiKIt_AI
./run.sh
```

Скрипт проверит Ollama, скачает модель (`qwen2.5:3b`, ~2 ГБ), создаст окружение и откроет приложение на http://localhost:8501.

<details>
<summary>Запуск вручную</summary>

```bash
ollama pull qwen2.5:3b
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

</details>

Попробуйте на примере: [`examples/sample_notes.txt`](examples/sample_notes.txt).

## Настройка

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OLLAMA_MODEL` | `qwen2.5:3b` | Модель; для качества лучше `qwen2.5:7b` |
| `OLLAMA_URL` | `http://localhost:11434` | Адрес Ollama |

## Как это устроено

| Файл | Назначение |
|---|---|
| [`app.py`](app.py) | Интерфейс Streamlit |
| [`core.py`](core.py) | Чтение файлов, разбиение на части, промпт и вызов Ollama, объединение результатов |
| [`reporting.py`](reporting.py) | Отчёт, уточняющие вопросы, PDF и Markdown |
| [`tests/`](tests) | Автотесты (`pytest`) |

Принципы: модели запрещено придумывать людей, даты и шаги (нет данных, значит «Неизвестно»), у элементов указан файл-источник, инструкции внутри документов не выполняются, а итог всегда проверяет человек.

## Ограничения MVP

- Нет OCR: сканы PDF не читаются
- Маленькие модели могут пропускать детали, поэтому результат нужно проверять
- Для PDF нужен системный шрифт с кириллицей (Arial на macOS, DejaVu на Linux)
